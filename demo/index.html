Retrain = train from scratch on the remaining rows (exact, slow). Newton = one Newton step from the old model on the remaining data, using the full fair objective’s gradient and Hessian (the paper’s method). Naive = “subtract the deleted rows’ gradient” while keeping the fairness penalty as if nothing changed; the pairwise penalty couples every pair across groups, so this misses the target. Gap = distance in weight space to the retrained model; “keep old model” shows how far the model should move. ε uses the repo’s data-dependent bound at δ = 10−4 and is a post-hoc estimate.
