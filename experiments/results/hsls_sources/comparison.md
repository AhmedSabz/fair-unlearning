# HSLS: authors' cleaned table (A) vs. independently built NCES table (B)

Supplementary comparison; same model, hyperparameters (λ = 1e-2, γ = 10, σ = 1), split seed 0 and noise vector. The two pipelines differ in several ways at once (below), so differences are not attributed to any single cause. Generated by `python -m experiments.hsls_sources`; configuration and hashes in `manifest.json`.

## Cohorts and labels

- A: 14,509 students (train/test 11,607 / 2,902); B: 14,843 (11,874 / 2,969).
- Students only in A: 0. Only in B: 334 (259 without S1M8GRADE, 75 not explained by a documented rule).
- Matching key: the row position in the original NCES student file (hsls_16_student_v1_0.csv, sorted by STU_ID), not a persistent STU_ID; the authors' table has no STU_ID and is indexed by that position. The run checks it against sex, race, labels and every observed raw value of 53 features.
- Shared students have the same train/test assignment (conflicts: 0); shared test cohort: 2,902.
- Label thresholds on X1TXMTH: A 0.154, B 0.14205 (median of B's training rows). Shared students labelled differently: train 59, test 23.

Known pipeline differences: rows (undocumented rule vs. questionnaire-completion rule); missing values (A treats all negative values as missing, including valid negative scores of X1MTHID/X1MTHEFF/X1MTHINT; B only NCES reserve codes); imputation (A: k-NN of unknown configuration on the full table before the split; B: KNNImputer(k=5) fitted on training rows); scaling (A: MinMax on the full table; B: MinMax fitted on training rows); label threshold (above). See data/README.md.

Evaluation sets: `native` = each source's own test set and labels; `shared_native` = the shared test students, each source scored against its own label definition (so the same students can carry different labels: 23 here); `shared_common_label` = the shared test students with one label for both sources (the authors' definition).

## Limitations

- The pipelines differ in cohort, missing values, imputation, scaling and label threshold simultaneously; differences between A and B cannot be attributed to any one of them.
- The 75 students without an explaining rule are kept in B; why the authors excluded them is unknown.
- One train/test split (seed 0) and five deletion seeds; std values reflect deletion seeds only.
- Unlearning covers the model only: preprocessing (scaling, imputation, label threshold) is fitted before deletion and kept.
- ε values (in deletion_raw.csv) are post-hoc estimates, not formal guarantees (README, "Noise and certificate"). Runtimes are single timings.
